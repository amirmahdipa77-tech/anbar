# Nature sounds — صدای طبیعت

Ambience beds and weather. The wind, rain and stream files loop seamlessly.

صدای محیط و آب‌وهوا. فایل‌های باد، باران و جوی آب بی‌درز لوپ می‌شوند.

| File | Length | Loop | Description | توضیح |
|---|---|---|---|---|
| [`wind.wav`](wind.wav) | 6.65s | yes | Rolling wind ambience, seamless loop. | صدای باد غلتان، لوپ بی‌درز. |
| [`rain.wav`](rain.wav) | 6.65s | yes | Steady rainfall with individual droplets, seamless loop. | باران یکنواخت با قطره‌های جدا، لوپ بی‌درز. |
| [`thunder.wav`](thunder.wav) | 4.5s | no | Distant thunder roll with a crackle on the attack. | رعد دور با ترق‌ترق در ابتدا. |
| [`stream.wav`](stream.wav) | 6.65s | yes | Small running stream with bubbling water, seamless loop. | جوی آب کوچک با حباب، لوپ بی‌درز. |

All files: 44.1 kHz, 16-bit PCM, mono, normalised to -1 dBFS.
همه فایل‌ها: ۴۴٫۱ کیلوهرتز، ۱۶ بیت، مونو، نرمال‌شده روی ۱- دسی‌بل.
