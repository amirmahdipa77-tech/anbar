# Interface sounds — صدای رابط کاربری

Notifications, taps, confirmations and errors for apps and websites.

نوتیف، کلیک، تأیید و خطا برای اپلیکیشن و وب‌سایت.

| File | Length | Loop | Description | توضیح |
|---|---|---|---|---|
| [`notification.wav`](notification.wav) | 1.0s | no | Two-tone bell notification, clean and familiar. | نوتیف دو نتی زنگی، تمیز و آشنا. |
| [`click.wav`](click.wav) | 0.09s | no | Very short tactile click for buttons and toggles. | کلیک بسیار کوتاه برای دکمه‌ها. |
| [`success.wav`](success.wav) | 0.9s | no | Three ascending bell notes for a completed action. | سه نت زنگی صعودی برای انجام موفق یک کار. |
| [`error.wav`](error.wav) | 0.55s | no | Two descending buzzy tones for an invalid action. | دو نت نزولی برای عمل نامعتبر. |
| [`message.wav`](message.wav) | 0.3s | no | Soft pop for a new chat message. | پاپ نرم برای پیام جدید. |

All files: 44.1 kHz, 16-bit PCM, mono, normalised to -1 dBFS.
همه فایل‌ها: ۴۴٫۱ کیلوهرتز، ۱۶ بیت، مونو، نرمال‌شده روی ۱- دسی‌بل.
