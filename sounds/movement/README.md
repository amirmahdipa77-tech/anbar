# Movement sounds — صدای حرکت

Footsteps, jumping and landing for characters.

قدم، پرش و فرود برای شخصیت‌ها.

| File | Length | Loop | Description | توضیح |
|---|---|---|---|---|
| [`footstep-gravel.wav`](footstep-gravel.wav) | 0.45s | no | Three crunching gravel steps for walking on dirt or rocks. | سه قدم روی شن و سنگ. |
| [`footstep-wood.wav`](footstep-wood.wav) | 0.4s | no | Single footstep on a wooden floor with body resonance. | یک قدم روی کف چوبی با رزونانس. |
| [`jump.wav`](jump.wav) | 0.5s | no | Short upward blip with air for jumping. | بلیپ صعودی کوتاه برای پرش. |
| [`land.wav`](land.wav) | 0.55s | no | Low thump and dust for landing after a jump. | ضربه بم برای فرود بعد از پرش. |

All files: 44.1 kHz, 16-bit PCM, mono, normalised to -1 dBFS.
همه فایل‌ها: ۴۴٫۱ کیلوهرتز، ۱۶ بیت، مونو، نرمال‌شده روی ۱- دسی‌بل.
